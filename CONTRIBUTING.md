# Contributing to Harness from First Principles

Thank you for your interest in contributing to this project! Contributions are welcome and your efforts to help improve the project are appreciated.

Follow the standard GitHub Fork + PR flow, ensure all tests pass and feel free to use AI. But you need to be able to explain each line of code, decision, design choice, etc. that have been made in your PR.

## Code of Conduct

Please follow our [Code of Conduct](CODE_OF_CONDUCT.md) to ensure a welcoming and respectful environment for all contributors.
